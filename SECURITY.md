# Security policy

## Supported versions

Genesis is a pre-release protocol. Only the latest release candidate receives
security fixes. Operators should follow the latest signed release tag and
content-hash manifest.

## Reporting a vulnerability

Do not publish private keys, exploit details, origin addresses, credentials,
or other sensitive evidence in a public issue. Use GitHub's private
vulnerability reporting for this repository. A public issue is appropriate
only when the report contains no sensitive operational or exploit material.

Include the affected version, the smallest reproducible request or Event, the
observed impact, and whether the issue affects protocol integrity, Node
availability, discovery, relay behavior, or package distribution.

Cryptographically valid content is not automatically trusted content. Reports
about false or unwanted Event text are policy questions unless they also show
a validation, isolation, confidentiality, or availability defect.
